## Evidence and release gaps

- The Sink README at the pinned commit explicitly describes analytics realtime as 10-second polling plus client-side replay, not a WebSocket or SSE stream. Any release claim should preserve that distinction.
- The adapted app README marks the parity checklist complete, but the source inspection above is stronger evidence: only three app-focused test files were observed (`admin-boundary`, `cloudflare-access`, and `link-proxy`), while the broader Sink API/unit suite was not ported as app tests. Treat the app checklist as intent until browser and integration evidence is attached.
- Portfolio analytics unit evidence and the private Cloudflare provider/RUM evidence are listed only by path; no token, raw PII, or provider response was copied into this document. The provider report confirms a parent-run check, not a deployed-origin acceptance check.
- Release QA should exercise each row on `www.akmalalif.com/admin` and `go.akmalalif.com`, including a fresh database migration, Access allowlist, bearer-only native API/MCP, advanced redirect gates, detailed-history authorization/retention, WAE/AE reports, R2 backup, AI-disabled behavior, health checks, and browser accessibility.
